# AGROMEC SFÂNTU GHEORGHE SA - Website Oficial

Site-ul web oficial al companiei **AGROMEC SFÂNTU GHEORGHE SA** (`agromecsfgheorghe.ro`), dezvoltat în **Angular 19/20** (Standalone Components, Signals, Reactive Forms).

---

## 🚀 Tehnologii Utilizate
- **Framework**: [Angular](https://angular.dev/) (Standalone Components, Signal-based State Management, Reactive Forms)
- **Styling**: Modern CSS Design System (Custom Properties, Flexbox/Grid, Responsive Breakpoints)
- **Multilingvism**: Română (RO), Maghiară (HU), Engleză (EN) cu schimbare dinamică
- **Componente**:
  - `Header` (navigație, orar, apel rapid, comutator limbă)
  - `Hero` (fotografii de înaltă rezoluție, statistici, CTA-uri)
  - `About` (istoric 1991, dotări, misiune, valori)
  - `Services` (activități auxiliare detaliate CAEN 0161)
  - `Communications` (anunțuri oficiale, convocatoare AGA, rapoarte financiare, căutare și filtrare, vizualizare modală cu opțiune de salvare/printare PDF)
  - `Contact` (date fiscale, formular reactiv de contact cu validare, hartă OpenStreetMap)
  - `Footer` (date legale, link-uri rapide, copyright)

---

## 💻 Instalare și Rulare Locală

1. **Instalare dependențe:**
   ```bash
   npm install
   ```

2. **Pornire server de dezvoltare:**
   ```bash
   npm start
   ```
   Accesați în browser: `http://localhost:4200/`

3. **Compilare pentru producție:**
   ```bash
   npm run build
   ```
   Fișierele optimizate vor fi generate în folderul `dist/agromec-app`.
